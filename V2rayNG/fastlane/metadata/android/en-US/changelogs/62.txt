Works even when the pool server is unreachable: some Iranian ISPs block the Cloudflare-fronted pool server outright, which left installs (especially fresh ones) stranded on an empty list with "couldn't refresh the server list". The app now ships with a bundled snapshot of the config pool — when the live fetch fails, the built-in list loads from inside the app itself, works immediately, and refreshes from the network automatically once the server is reachable again. A toast tells you when the backup list was served.
